{% if not module_wf_enabled %}
Para crear sitios con upstream 127.0.0.1:* debes activar primero el módulo WardNode WF — esto permite bloquear el puerto en iptables para que solo el proxy WAF pueda alcanzar el servicio.
{% else %}
Los upstreams en 127.0.0.1:* quedan protegidos automáticamente: el puerto se bloquea en iptables (raw/PREROUTING) y solo el proxy WAF puede alcanzarlo desde loopback.
{% endif %}
Si lo dejas desactivado, el WAF arranca en modo solo detección — las reglas CRS registran ataques en Eventos sin bloquearlos.
