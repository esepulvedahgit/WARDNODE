Cómo configurar

  1. Generar la clave de cifrado (una sola vez en el anfitrión):
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
  1. Agregar el resultado a .env: WARDNODE_SECRET_KEY=<resultado>
  2. Reiniciar el servicio console: docker compose restart console
  3. Ingresar Account ID y License Key en el formulario de arriba y guardar.
  4. Las credenciales quedan cifradas en la DB — solo WARDNODE_SECRET_KEY necesita protección.
