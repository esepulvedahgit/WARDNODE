{# ── Instrucciones de despliegue ── #}

Despliegue en el VPS

  1. Copiar archivos de configuración al VPS

    El directorio observability/ debe estar junto a docker-compose.vps.yml: 

    scp -r observability/ usuario@IP_VPS:/ruta/wardnode/

  2. Configurar contraseña de Grafana

    Añadir en .env.prod en el VPS: 

    GRAFANA_ADMIN_PASSWORD=tu_contrasena_segura

  3. Iniciar el stack de observabilidad

    docker compose -f docker-compose.vps.yml --profile obs up -d

    Reiniciar también los servicios existentes para activar el logging driver Fluent Bit: 

    docker compose -f docker-compose.vps.yml up -d --force-recreate console proxy
{# ── Escenario B: dominio con site configurado en WardNode ── #}

Dominio con site activo en WardNode

solo si aplica

Si el dominio ya está configurado como site protegido en Proxy & WAF, el catch-all del nginx-obs.conf no aplica. Agrega manualmente la location en Configuración del site → Nginx extras → Bloque server: 

location /obs/ {
    proxy_pass         http://grafana:3000/obs/;
    proxy_set_header   Host              $host;
    proxy_set_header   X-Real-IP         $remote_addr;
    proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
    proxy_set_header   X-Forwarded-Proto $scheme;
    proxy_http_version 1.1;
    proxy_set_header   Upgrade           $http_upgrade;
    proxy_set_header   Connection        "upgrade";
    proxy_read_timeout 300s;
}
